# Ghosium Browser

Ghosium Browser is a privacy-oriented Windows x64 browser distributed by **Brendigo**. Version **0.7.0** focuses on a Ghosium-only product experience, multilingual installation, lower background network activity, weak-PC optimization, Ghosium Search and the new Ghosium Store catalog.

## Product identity

All Ghosium-controlled user-facing surfaces use the **Ghosium** brand. Product links generated by Ghosium point only to Ghosium-owned domains:

- https://ghosium.com/
- https://search.ghosium.com/
- https://store.ghosium.com/
- https://ghosium.com/legal/terms
- https://ghosium.com/legal/privacy-policy
- https://ghosium.com/legal/licenses
- https://ghosium.com/support
- https://ghosium.com/security

Required third-party notices remain in `THIRD_PARTY_NOTICES.md` and the installed license material. Those notices are legal attribution, not Ghosium product branding.

## Desktop architecture

The Ghosium-owned Windows launcher is written in **C++20**. There is no Tauri application wrapper, WebView2 browser shell, Rust browser core or TypeScript/Vite browser runtime.

```text
Ghosium-Browser.exe
  -> runtime/Ghosium-Engine.exe
  -> extension/            Ghosium Privacy + New Tab
  -> search-provider/      Ghosium Search integration
```

HTML, CSS and JSON under the bundled components are presentation/configuration resources and contain no custom browser JavaScript runtime.

## Ghosium Search

New-tab and default search entry points use:

```text
https://search.ghosium.com/?q={searchTerms}
```

The source for the database-free shared-hosting service is included in `search-web/`. It uses PHP and `storage/data/*.json` rather than a SQL database.

## Ghosium Store

The source for `https://store.ghosium.com/` is included in `store-web/`.

The first Store release is a privacy-focused curated catalog with a JSON API and no database, analytics, remote fonts or third-party assets. Automatic public one-click extension installation will only be enabled after deeper engine integration can provide it without weakening extension security.

## Privacy defaults

Ghosium disables browser sync, crash reporting, background browser mode, background networking subsystems, Domain Reliability reporting and hyperlink-auditing pings at launcher level. The bundled declarative privacy rules block selected third-party trackers and remove common campaign/click identifiers.

Ghosium does not claim anonymity. Websites intentionally visited by the user still receive normal web requests and may use their own cookies or fingerprinting techniques subject to browser controls and Ghosium filtering.

## Weak-PC optimization

Systems with **8 GiB RAM or less** automatically use Low Memory mode:

- renderer process limit: 6
- disk cache budget: 128 MiB

The sandbox, certificate validation and core process isolation remain enabled. Users can force normal resource behavior with `--ghosium-balanced` or force the constrained profile with `--ghosium-low-memory`.

## Stable Release assets

A stable release intentionally attaches only:

- `Ghosium-Browser-Setup.exe`
- `Ghosium-Browser-Portable.exe`

GitHub automatically provides the matching **Source code (zip)** and **Source code (tar.gz)** archives for the release tag. Search/Store web source is therefore delivered through the source archive instead of adding extra release ZIP assets.

## Setup

The Setup EXE:

- runs per-user without administrator privileges
- shows the Brendigo BSD 3-Clause license before installation
- identifies Brendigo as Company/Publisher
- lets the user choose among 30 languages
- installs only Ghosium-owned shortcuts and Ghosium-owned support/legal URLs
- records the selected browser language
- includes all required third-party license material inside the installed application

## Portable

`Ghosium-Browser-Portable.exe` is a single release executable. It extracts the runtime to a temporary directory, keeps user data in `Ghosium-Portable-Data` beside the EXE, waits for Ghosium Browser to close and then removes the temporary runtime.
