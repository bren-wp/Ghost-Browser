# Ghosium Browser

Ghosium Browser is a privacy-oriented Windows x64 browser distribution that runs the open-source Chromium runtime directly. There is no Tauri, WebView2 application wrapper, Rust browser core or custom JavaScript browser runtime.

Version **0.6.0** uses one Ghosium-owned executable language for the desktop browser: **C++20**. Chromium supplies the browser engine and standard Chrome-style desktop features; Ghosium supplies a hardened native launcher, declarative privacy components, branded new-tab/search integration, release provenance and a separate PHP shared-hosting service for `search.ghosium.com`.

## What is included

- upstream Chromium browser runtime, pinned to a numeric snapshot revision
- native C++20 launcher with Windows process mitigations
- Chromium tabs, windows, omnibox, settings, bookmarks, history and downloads
- Chromium password/autofill controls, site permissions, DevTools and extensions
- Ghosium Privacy Manifest V3 declarative rules
- Ghosium Search as the bundled new-tab and omnibox search endpoint
- no custom browser JavaScript runtime
- automatic Low Memory mode on Windows systems with 8 GiB RAM or less
- normal Balanced mode on stronger systems
- per-user Windows Setup EXE and Portable ZIP
- SHA-256 checksums and exact Chromium source/build metadata
- database-free `Ghosium-Search-Shared-Hosting` PHP/JSON package
- stable GitHub Release and versioned GitHub Package/OCI release bundle

## Browser architecture

The desktop browser has one Ghosium-owned executable source layer:

```text
launcher/main.cpp  ->  runtime/chrome.exe (Chromium)
                     + extension/ (declarative privacy + NTP)
                     + search-provider/ (single-purpose search override)
```

HTML, CSS and JSON files are presentation/configuration resources and contain no executable browser scripts. The `search-web/` directory is a separate server application written in PHP for commodity shared hosting; it is not part of the browser executable.

## Ghosium Search

Both the new-tab search form and bundled Chromium search-provider component point to:

```text
https://search.ghosium.com/?q={searchTerms}
```

The repository contains the complete `search.ghosium.com` implementation in `search-web/`. By default it searches a local JSON index generated by its own CLI crawler. No third-party search vendor URL is hardcoded into the browser. An optional generic server-side JSON provider can be enabled later if broader coverage is needed; the API key remains on the server.

A single shared-hosting machine plus JSON storage cannot realistically maintain a complete index of the public web. For a truly global independent Ghosium index, the crawler/index layer must eventually move to dedicated distributed infrastructure. The shared-hosting implementation is intentionally a secure, deployable first-party starting point rather than pretending to be a global crawler.

## Privacy defaults

The launcher starts Chromium with a dedicated local profile and disables browser sync, crash reporting, background browser mode, Domain Reliability reporting and hyperlink-auditing pings. The Ghosium privacy component uses declarative rules to block selected third-party tracker/advertising requests and remove common campaign/click identifiers from top-level navigations.

Ghosium does not run application analytics, advertising identifiers or a user-profile backend. This does not mean every website becomes unable to identify a visitor: a site you intentionally visit still receives network requests and can use its own cookies/fingerprinting subject to Chromium controls and Ghosium filtering. See `PRIVACY.md`.

## Low Memory mode

If Windows reports **8 GiB RAM or less**, the launcher automatically adds conservative upstream Chromium resource limits:

- renderer process limit: 6
- disk cache budget: 128 MiB

The sandbox, certificate validation and core Chromium security isolation are not disabled to save RAM. Use `--ghosium-balanced` to force normal Chromium resource behavior or `--ghosium-low-memory` to force the constrained profile. See `docs/PERFORMANCE.md`.

## Local profile

```text
%LOCALAPPDATA%\Ghosium Browser\User Data
```

The Portable ZIP changes application installation style, not profile privacy: profile data still uses the dedicated local directory unless the architecture is changed in a future release.
